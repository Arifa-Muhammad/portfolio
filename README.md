# My Portfolio Website

A personal portfolio website built using HTML and CSS to showcase my skills, education, and web development projects.

## Features

- Professional and modern design
- About Me section
- Skills section, including HTML, CSS, and WordPress
- Education table
- Responsive design improvements in progress

## Technologies Used

- HTML5
- CSS3

## Project Structure

- `main.html` — Main portfolio webpage
- `style.css` — Styling and layout

## Getting Started

1. Clone or download this repository.
2. Open `main.html` in your browser to view the website.
